Connect YouTube to Clip4X

One-time setup so Clip4X can upload your clips as Shorts under your own account. ~5 minutes. Free.

Why your own credentials? Clip4X is open source, so it ships no shared Google keys. You create a personal OAuth client once. Uploads then run under your Google account and your private quota — no app verification, no shared limits, and nothing is typed into the app except one environment variable.

Steps

  1. Create a Google Cloud project
    Go to the Cloud Console, create a project (any name, e.g. clip4x), and select it.
  2. Enable the YouTube Data API v3
    In APIs & Services → Library, search YouTube Data API v3 and click Enable.
  3. Configure the OAuth consent screen
    Under APIs & Services → OAuth consent screen, choose External, fill in the app name and your email, and save. When prompted for scopes you can skip adding any — Clip4X requests youtube.upload at sign-in.
  4. Add yourself as a test user
    On the consent screen's Audience / Test users section, add the Google account whose channel you'll post to. Leave the app in Testing mode — no verification needed for your own use.
  5. Create the OAuth client
    Under APIs & Services → Credentials → Create credentials → OAuth client ID, pick application type Desktop app. Create it, then copy the Client ID (looks like xxxx.apps.googleusercontent.com).
  6. Tell Clip4X your Client ID
    Set the environment variable before launching the app: 
    export CLIP4X_YT_CLIENT_ID="xxxx.apps.googleusercontent.com"
# only if your client also shows a secret:
export CLIP4X_YT_CLIENT_SECRET="..."
    Add the export line to ~/.zshrc to make it permanent.
  7. Connect in the app
    Launch Clip4X → Connect YouTube → approve in the browser (you'll see an "unverified app" notice — that's expected for your own Testing project; continue). Then use Upload as Shorts or Schedule….

How Shorts & scheduling work

TopicDetail
What makes a ShortVertical/square, ≤ 3 min, with #Shorts in the title/description. Clip4X exports 9:16 and adds #Shorts automatically.
Upload nowPublishes as public immediately.
ScheduleUploads as private with a publishAt time; YouTube auto-publishes. Clip4X need not be running then.
Token storageRefresh token kept in the macOS Keychain (audio.witch.clip4x.youtube).
Testing-mode limits (per user): ~6 uploads/day (each upload costs 1600 of the 10,000 daily quota units), and the OAuth approval may expire after ~7 days — just click Connect again. These are Google's limits for unverified personal projects; they're plenty for regular posting. To raise them you'd submit the project for Google's OAuth verification and a quota increase.

Trouble connecting? Make sure the Client ID is a Desktop app type, your account is listed as a test user, and the YouTube Data API v3 is enabled.
